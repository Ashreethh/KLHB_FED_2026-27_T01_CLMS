Abstract:
The Community Library Management System is a Java console-based application designed to replace a traditional paper-based library register. The system helps a community library manage its book catalogue, member records, and borrowing and returning activities in an organized way. Users can add, search, and remove books, register members, issue available books, return borrowed books, and identify overdue loans and fines. The application also provides reports such as the most-borrowed books and genres. The project is designed using fundamental Java programming concepts covered in class, including variables, operators, conditional statements, loops, methods, arrays, searching, and basic data handling. The main goal is to make library operations faster, clearer, and less prone to record-keeping errors while providing useful information about community reading patterns.
